A one-line midnight fridge roast for make.fun's "Midnight Fridge Roast" bounty ($2, top 10, 1st $0.63). The smart fridge locks itself after midnight like a nightclub bouncer with a guest list, and the roast is the door speech: the leftovers aren't on the list tonight, and neither are you. The winning roast becomes the fridge's official midnight apology note.

## Run it

```sh
node main.ts
```

It writes the roast to `/output/entry.txt` (one line, 131 characters).
